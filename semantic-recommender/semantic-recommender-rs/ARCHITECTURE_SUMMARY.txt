MEMORY SAFETY STRATEGY
----------------------
1. RAII Wrappers:       GpuTensor<T> with automatic Drop cleanup
2. Shared State:        Arc<RwLock<T>> for GPU tensors
3. Lock-Free:           DashMap for user ID → index mapping
4. Zero Unsafe:         Business logic only uses safe Rust
5. Thread Safety:       Send + Sync for CUDA contexts
